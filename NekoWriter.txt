NekoWriter（MVP）

本次实现仅实现MVP，所以本次实现的产物应当有尽可能多的可拓展性，为以后修改删除增加业务流程提供足够的自由度。

已确认的补充约定：{
    docs/01-implementation-plan.md 第3.2节中的D01至D16共16项补充约定，全部采用该表中的方案决策，作为本需求的组成部分。
    对应实现行为与验收以docs/02-implementation-spec.md为准，后续实施直接应用这些已确认决策。
    D16采用已纳入阶段上下文折叠需求后的内容：保留审核通过产物的完整纯文本，超出上下文窗口时明确报错，不自动摘要或裁剪。
}

Dashboard模块：{
    Token Usage

}
项目模块：{
    每个项目有：{
        项目名称
        项目设置：{
            模型
            思考等级
            辅助工具调用预算
        }
        小说版本
    }
    小说：{
        小说标题
        章节

    }

    小说工作台：{
        使用分层状态机进行状态管理

        章节列表：{
            点击后scroll到对应章节
        }
        章节内容展示器：{
            实时更新
        }
        Dock栏：{
            通用：{
                审核/意见输入框：{
                    引用产物内容
                    审核专有：{
                        委托审核按钮
                    }
                }
            }
            准备阶段：{
                询问用户：{
                    单选/多选：{
                        除了给定选项外，用户可以提供自定义答案
                    }
                }
                审核状态：{
                    4个Tab，分别对应同一准备阶段的背景设定、资料收集、人物设定、小说粗纲审核框
                }
            }
            正文阶段：{
                章节指导：{
                    文本
                }
            }
        }
        生成逻辑：{
            时间线：{
                初始化->准备阶段->正文阶段->完本->(可选)番外
            }
            初始化：{
                创建数据库必要行
            }
            准备阶段：{
                带有硬性目标的AgentLoop
                Agent在提交完所有待提交的内容并通过审核后即完成该阶段并进入下一阶段
                提交内容：{
                    背景设定，资料收集 ，人物设定，小说粗纲
                }
                Agent在提交完所有待提交的内容进入审核状态
                能调用的工具：{
                    询问用户:{
                        免费
                    }
                    查询知识库：{
                        消耗quota
                    }
                    联网研究：{
                        消耗quota
                    }
                }
            }
            正文阶段：{
                章节开始前，用户可以输入章节指导
                时间线：{
                    撰写细纲->撰写正文->审核章节
                }
                撰写细纲：{
                    撰写完成后交由用户审核，可委托审核Agent；通过后才进入正文撰写
                    能调用的工具：{
                        询问用户:{
                            免费
                        }
                        查询知识库：{
                            消耗quota
                        }
                        联网研究：{
                            消耗quota
                        }
                    }
                }
                撰写正文：{
                    模式：{
                        两个模式可以随时切换
                        AutoApprove：{
                            用户可以随时暂停，暂停后在新一个toolcall到来时挂起。
                            用户可以随时提供意见。
                            如果用户在暂停时提供意见：{
                                如果暂停时没有挂起，则将用户意见附于最近一个toolcall返回值中，并取消暂停状态
                                如果暂停时挂起了，则恢复挂起的toolcall，并将用户意见附于toolcall返回值中，取消暂停状态
                            }
                            如果用户在其他时候提供意见，则将用户意见附于最近一次新的toolcall返回值中
                            用户可以在有未提交给agent的意见时继续提交意见，所有排队的意见都将在提交给agent时排空。
                        }
                        ApproveRequired：{
                            用户对Agent每一次正文编辑操作（在展示器中高亮显示）给出意见（意见为空时表示Approved）
                            用户提交意见后拒绝本次编辑操作，并给出用户提供的意见
                        }
                    }
                    能调用的工具：{
                        询问用户:{
                            免费
                        }
                        append_content:{
                            append对象为本章正文
                            参数为content
                            免费
                        }
                        replace_content:{
                            replace对象为本章正文
                            参数为old_str,new_str
                            old_str无匹配或不止一处匹配时拒绝
                            免费
                        }
                    }
                }
            }
        }
        审核委托：{
            对于所有审核，都可以委托给审核agent进行审核
            对于不同的审核，有不同的提示词
            审核Agent最终返回：{
                通过：bool (Required)
                置信度：number 范围 [0,1] (Required)
                问题列表: List<string> (Required)
            }
        }
        审核：{
            对于所有审核，当审核不通过时，Agent根据意见对提交的产物进行修订，然后重新提交审核，直到审核通过。
        }
        内建系统/用户提示词管理（项目级）{
            所有条目与系统级一致
            项目级更改优先级比系统级高
        }
        实现细则：{
            每个请求都基于最新的设置构建
            在不改变语义的情况下尽可能地提升缓存命中率
            阶段上下文折叠：{
                所有产物在审核通过后，当前阶段的历史消息在Agent的上下文中折叠成仅产物内容的纯文本。
                当前阶段有多个必需产物时，全部通过审核后统一折叠。
                折叠保留审核通过的完整产物内容，不生成摘要，不附带提问、工具调用、审核意见等过程消息。
                折叠对后续请求生效，原始历史消息和审核记录仍在本地保存。
            }
        }
    }
}
